# NEXORA

Protótipo web inicial da plataforma NEXORA — catálogo de jogos com interface responsiva.

## Abrir
Abra `index.html` em um navegador. Nenhuma instalação ou build é necessária.

## Recursos de demonstração
- Catálogo de jogos e busca
- Filtros por categoria
- Cartões de experiências
- Modal de modo visitante/demo
- Interface responsiva

## Limitações
Ainda não possui contas reais, backend, jogos executáveis, multiplayer, chat em tempo real ou matchmaking. Os botões de jogos demonstram a interface e não iniciam jogos reais.
