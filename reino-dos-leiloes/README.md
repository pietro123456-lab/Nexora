# Reino dos Leilões 🏛️

Jogo fictício de leilões com moedas virtuais, itens colecionáveis, lances simulados, inventário, ranking e recompensas diárias.

## Como jogar
Abra `index.html` no navegador ou configure GitHub Pages para publicar.

## Funcionalidades
- Mercado fictício com busca e filtros
- Lances simulados
- Inventário e histórico de lances
- Ranking de magnatas
- Recompensa diária
- Criar leilões
- Persistência via localStorage
- Layout responsivo

Sem dinheiro real, pagamentos ou compras.
